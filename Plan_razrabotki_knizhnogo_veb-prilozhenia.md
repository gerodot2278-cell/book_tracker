# Roadmap разработки: Эстетичный книжный дневник и сообщество

> **Концепт:** Персональный скрапбук-трекер чтения с интерактивным медиа-календарем (в стиле Telegram) и живой социальной лентой цитат, фотографий и недельных топов.

---

## 1. Стек технологий и архитектура

Для максимального удобства при «вайбкодинге» (разработке с помощью AI-ассистентов: Cursor, Lovable.dev или Bolt.new) выбран современный, модульный и понятный нейросетям стек:

* **Фронтенд:** Next.js (App Router, React, TypeScript).
* **Стилизация & UI:** Tailwind CSS + компонентная база `shadcn/ui` + иконки `lucide-react`.
* **Графика & Визуализация:** `recharts` (для графиков темпа чтения) + `date-fns` (для работы с календарем).
* **Бэкенд & База данных:** **Supabase**:
  * **Auth:** Регистрация/вход (Email + пароль, вход через Google).
  * **PostgreSQL:** Хранение книг, логов, цитат и топов.
  * **Storage:** Хранение сжатых фотографий разворотов и обложек.
  * **Realtime:** Живое обновление ленты без перезагрузки страниц.
* **Хостинг:** Vercel (интегрируется с GitHub в один клик).

---

## 2. Схема базы данных (Database Schema)

Простая, масштабируемая реляционная модель под Supabase:

### `profiles` (Профили пользователей)
* `id` (uuid, primary key, matches auth.users)
* `username` (text, unique)
* `avatar_url` (text, nullable)
* `bio` (text, nullable)
* `created_at` (timestamptz)

### `books` (Каталог книг)
* `id` (uuid, primary key)
* `title` (text)
* `author` (text)
* `total_pages` (int4)
* `cover_url` (text, nullable)
* `created_at` (timestamptz)

### `user_books` (Книжная полка пользователя)
* `id` (uuid, primary key)
* `user_id` (uuid, foreign key -> profiles.id)
* `book_id` (uuid, foreign key -> books.id)
* `status` (text: `'reading'`, `'completed'`, `'planned'`)
* `current_page` (int4, default: 0)
* `rating` (int2, 1-5, nullable)
* `created_at` (timestamptz)

### `reading_logs` (Журнал чтения — фундамент календаря и ленты)
* `id` (uuid, primary key)
* `user_id` (uuid, foreign key -> profiles.id)
* `book_id` (uuid, foreign key -> books.id)
* `pages_read` (int4) — количество прочитанных страниц за сессию
* `end_page` (int4) — на какой странице остановился
* `quote` (text, nullable) — выписанная цитата
* `note` (text, nullable) — короткий комментарий/мысль
* `photo_url` (text, nullable) — фото разворота/страницы
* `is_public` (boolean, default: false) — тумблер видимости в общей ленте
* `log_date` (date) — дата сессии чтения (для календаря)
* `created_at` (timestamptz)

### `book_tops` (Пользовательские подборки и топы)
* `id` (uuid, primary key)
* `user_id` (uuid, foreign key -> profiles.id)
* `title` (text) — например, «Топ-5 фэнтези года»
* `description` (text, nullable)
* `is_public` (boolean, default: true)
* `created_at` (timestamptz)

### `book_top_items` (Элементы топа)
* `id` (uuid, primary key)
* `top_id` (uuid, foreign key -> book_tops.id)
* `book_id` (uuid, foreign key -> books.id)
* `rank` (int2) — порядковое место (1, 2, 3...)
* `comment` (text, nullable)

### `log_likes` & `log_comments` (Социальные взаимодействия)
* Привязываются к `reading_logs.id` для живого общения в ленте.

## 3. Поэтапный план разработки

```
┌────────────────────────────────────────────────────────┐
│ ЭТАП 1: Локальный прототип UI (Mock-данные)           │
│   → Карточка книги + Форма записи + Календарь-сетка    │
└─────────────────────────┬──────────────────────────────┘
                          ▼
┌────────────────────────────────────────────────────────┐
│ ЭТАП 2: Подключение Supabase                           │
│   → Регистрация/Вход + Загрузка картинок (Storage)     │
└─────────────────────────┬──────────────────────────────┘
                          ▼
┌────────────────────────────────────────────────────────┐
│ ЭТАП 3: Личный кабинет и Медиа-календарь               │
│   → Полноценная логика архива + Статистика страниц     │
└─────────────────────────┬──────────────────────────────┘
                          ▼
┌────────────────────────────────────────────────────────┐
│ ЭТАП 4: Социальный слой и Live Feed                    │
│   → Публичная лента + Realtime + Топы недели           │
└─────────────────────────┬──────────────────────────────┘
                          ▼
┌────────────────────────────────────────────────────────┐
│ ЭТАП 5: Мобильная полировка, PWA и Деплой              │
│   → Адаптив, манифест на экран телефона, запуск        │
└────────────────────────────────────────────────────────┘
```

---

### Этап 1: Интерактивный UI-прототип (Без бэкенда)
**Цель:** За один вечер собрать визуал, кликабельность и анимацию на фейковых данных (mock data).

1. **Главный экран Dashboard:**
   * Секция «Читаю сейчас»: карточка с обложкой, шкалой прогресса (например, 140/320 стр.) и кнопкой «Записать прогресс».
   * Форма быстрой записи:
     * Поле «Сколько страниц прочитал».
     * Текстовые поля для цитаты и личной мысли.
     * Загрузка изображения (превью в интерфейсе).
     * Переключатель: «Лично» / «В общую ленту».
2. **Медиа-календарь (Telegram-стиль):**
   * Сетка текущего месяца.
   * Если в mock-данных на дату есть фото — ячейка дня заливается круглым превью снимка.
   * Клик по дню — всплывающее модальное окно с деталями прочитанного за этот день.

---

### Этап 2: Бэкенд, Авторизация и Файлы (Supabase)
**Цель:** Превратить статический макет в работающее приложение с сохранением данных.

1. **Инициализация Supabase:**
   * Создание таблиц по подготовленной схеме через SQL-редактор Supabase.
   * Настройка политик безопасности (Row Level Security): пользователь может редактировать только свои логи.
2. **Аутентификация:**
   * Модальное окно входа через Email + Google OAuth.
   * Привязка профиля (`profiles`) к новой учетной записи.
3. **Хранилище медиа:**
   * Создание публичного бакета `reading-photos` в Supabase Storage.
   * Сжатие фото перед загрузкой на клиенте с помощью библиотеки `browser-image-compression` (снижение размера с 10 МБ до 300 КБ).

---

### Этап 3: Личный кабинет и Аналитика
**Цель:** Создать замкнутую экосистему персонального книжного дневника.

1. **Связка календаря с реальной БД:**
   * Запрос к `reading_logs` с фильтрацией по выбранному месяцу.
   * Динамическое отображение превью и счетчиков страниц в датах.
2. **Виджеты статистики:**
   * Счетчик прочитанных страниц за текущую неделю.
   * График активности по дням (столбчатая диаграмма через Recharts).
   * Подсчет непрерывной серии чтения (Streak: «Читаешь 6 дней подряд»).
3. **Конструктор персональных Топов:**
   * Страница создания подборки (например, «Топ-5 книг 2026 года»).
   * Добавление книг с указанием мест и комментариев.

---

### Этап 4: Социальная лента и Тренды недели
**Цель:** Выход в комьюнити и добавление реалтайм-механик.

1. **Лента сообщества (Explore / Feed):**
   * Отображение только тех логов, у которых флаг `is_public = true`.
   * Карточка поста: автор, книга, фото разворота, цитата с акцентным оформлением, дата.
2. **Realtime-обновление:**
   * Подключение `supabase.channel('public:reading_logs')`.
   * Анимация появления нового поста вверху ленты без перезагрузки экрана.
3. **Недельные чарты:**
   * SQL-запрос / функция Supabase для агрегации активности за последние 7 дней:
     * Самая читаемая книга недели (по сумме страниц/сессий).
     * Самая цитируемая книга недели.
   * Блок в боковой колонке на десктопе или отдельная вкладка на мобилке.

---

### Этап 5: Адаптивность, PWA и Запуск
**Цель:** Подготовить сайт к повседневному использованию с мобильного телефона.

1. **Мобильный UX:**
   * Нижняя навигационная панель (Bottom Navigation Bar): «Дневник», «Календарь», «Лента», «Профиль».
   * Свайп-шторки (Bottom Sheets через `vaul` / `shadcn Drawer`) вместо тяжелых модальных окон.
2. **PWA (Progressive Web App):**
   * Настройка `manifest.json` и иконок.
   * Возможность нажать «Добавить на главный экран» на iOS и Android (сайт открывается как отдельное приложение без рамок браузера).
3. **Деплой:**
   * Подключение репозитория к Vercel. Настройка переменных окружения Supabase.

## 4. Готовые промпты для вайбкодинга

Используй эти формулировки при общении с AI-инструментом (Cursor, Lovable, Bolt):

### Промпт 1: Сборка интерактивного медиа-календаря
```text
Создай адаптивный React-компонент интерактивного календаря чтения для Next.js с использованием Tailwind CSS и date-fns.
1. Календарь отображает сетку дней текущего месяца с возможностью переключения месяцев назад/вперед.
2. На вход компонент принимает массив объектов логов чтения: { date: string, pagesRead: number, photoUrl?: string, quote?: string, bookTitle: string }.
3. Если на день есть лог с фотографией (photoUrl), ячейка этого дня должна отображать фото в виде круглой миниатюры или фонового круга (как в медиа-календаре Telegram).
4. Если есть только прочитанные страницы без фото, покажи аккуратную точку или бейдж "+X стр".
5. При клике на день открывается модальное окно/шторка со списком всех записей за этот день с крупной фотографией, цитатой и количеством страниц.
6. Оформи в современном минималистичном стиле (светлая/темная тема, мягкие скругления).
```

### Промпт 2: Форма добавления сессии чтения
```text
Создай компонент формы "Зафиксировать чтение" на Tailwind CSS и shadcn/ui.
Форма должна содержать:
1. Выбор книги из списка текущих или поле ввода названия новой книги.
2. Числовое поле: "Сколько страниц прочитано сегодня".
3. Поле для цитаты (с красивой иконкой кавычек).
4. Поле для личной заметки или впечатления.
5. Инпут загрузки изображения с возможностью предпросмотра выбранного фото и кнопкой удаления.
6. Стильный Switch/Toggle переключатель: "Опубликовать в общую ленту" (по умолчанию выключен, поясняющий текст: "Если выключено — запись видна только в вашем личном календаре").
7. Кнопку сохранения с анимацией загрузки.
```

### Промпт 3: Живая лента с Supabase Realtime
```text
Напиши клиентский компонент ленты публикаций (Community Feed) для Next.js, интегрированный с Supabase.
1. Компонент запрашивает последние 20 записей из таблицы reading_logs, где is_public = true, включая данные о книге (title, author) и авторе поста из таблицы profiles (username, avatar_url).
2. Подключи Supabase Realtime подписку на таблицу reading_logs: при получении события INSERT с is_public = true новая запись плавно добавляется в самый верх списка.
3. Карточка поста должна содержать: шапку с аватаром и никнеймом, обложку книги, фотографию страницы (если прикреплена), блок цитаты с акцентным левым бордером, заметку и дату публикации.
```

## 5. Правила вайбкодинга: как не сломать проект

1. **Одно изменение за один промпт:** Никогда не проси нейросеть «сделай ленту, авторизацию и поменяй цвета календаря» одновременно. Сначала календарь. Проверил, закоммитил в Git. Затем авторизация.
2. **Храни схему БД под рукой:** Всегда держи в корне проекта файл `supabase_schema.sql`. Если нейросеть начинает выдумывать несуществующие колонки в таблицах, напоминай ей: *«Сверяйся со схемой в supabase_schema.sql»*.
3. **Сжатие на клиенте обязательно:** Загрузка тяжелых необработанных фото быстро забьет базу и вызовет фризы на мобилках. Компрессия перед `upload` решает эту проблему на корню.
4. **Mobile First:** Всегда тестируй изменения с открытой панелью разработчика в режиме эмуляции экрана смартфона (iPhone 14 / Pixel). 80% пользователей будут заливать цитаты именно с телефона во время чтения.
